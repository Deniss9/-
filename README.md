Logic Stack Entry 2.0 Public Preview 0.1.4

这是 Logic Stack Entry 2.0 的第一版公开预览。

定位

该版本是 TradingView 交易辅助指标，不是已经验证稳定盈利的自动策略。

它用于整理：

市场环境；

VWAP与SD价值区；

pVWAP与上一周期价值区；

回归通道；

早期观察与完整转折；

结构、动能与K线证据；

静态入场、止损、目标和RR；

计划距离提示与静态参考失效。
